Dokumentasi

Cara kerja, cakupan, dan cara membaca hasil Cyber Web Scanner.

Tentang

Cyber Web Scanner melakukan pemeriksaan pasif terhadap konfigurasi keamanan sebuah website. Pemindai hanya mengirim permintaan HTTP biasa seperti browser, lalu menilai respons yang benar-benar dikirim server. Tidak ada serangan, brute force, atau upaya eksploitasi.

Cara Menggunakan

  1. Masukkan domain atau URL di halaman Pindai, misalnya contoh.com. Jika protokol tidak ditulis, HTTPS dicoba lebih dulu, lalu HTTP.
  2. Tunggu proses pemindaian, biasanya 5 sampai 30 detik.
  3. Baca grade dan daftar temuan, lalu buka bagian bukti untuk melihat header mentah dari server.
  4. Unduh laporan sebagai PDF bila diperlukan.

Skor dimulai dari 100 dan dikurangi untuk setiap temuan.

Arti Grade

  • A
    Skor 90–100. Konfigurasi dasar sangat baik.
  • B
    Skor 80–89. Baik, dengan beberapa kekurangan kecil.
  • C
    Skor 70–79. Ada kekurangan yang perlu diperbaiki.
  • D
    Skor 60–69. Kekurangan signifikan.
  • F
    Skor di bawah 60. Ada masalah serius.
  • N/A
    Pemindaian tidak valid (diblokir WAF, error server, atau tidak dapat dihubungi). Skor tidak dihitung.

Cara Menghindari Hasil Palsu

  • Banyak server membalas HTTP 200 untuk alamat apa pun. Karena itu file seperti /.git/HEAD atau /.env hanya dilaporkan jika isinya cocok dengan format file tersebut, bukan sekadar status 200.
  • Nama header dicocokkan tanpa membedakan huruf besar dan kecil.
  • robots.txt dan file sensitif selalu dicek di akar domain, bukan di path yang dimasukkan.
  • Jika situs memblokir pemindai (misalnya tantangan Cloudflare) atau membalas error 5xx, hasil ditandai tidak valid dan tidak diberi skor.
  • Setiap pemindaian menyimpan bukti: URL akhir, status HTTP, waktu respons, dan header mentah.

Batasan

  • Hanya halaman yang dimasukkan yang diperiksa; tidak ada crawling ke halaman lain.
  • Konten yang dimuat lewat JavaScript tidak diperiksa.
  • Bukan uji penetrasi: celah aplikasi seperti SQL injection, XSS, atau autentikasi lemah tidak diuji.
  • Grade A berarti konfigurasi dasar baik, bukan jaminan website bebas celah.
  • Riwayat disimpan di server dan dapat terhapus saat layanan dimulai ulang.

Etika Penggunaan

Gunakan pemindai ini hanya pada website milik Anda atau yang Anda punya izin untuk memeriksanya. Walaupun pemeriksaannya pasif, memindai sistem orang lain tanpa izin dapat melanggar kebijakan layanan atau hukum yang berlaku.
